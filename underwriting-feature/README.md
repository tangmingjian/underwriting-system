特征分级：
    * 订单级别特征：取订单号，或者用订单号去查询订单缴费状态，结果存在订单自己上
    * 订单级别聚合下级批量取数特征：订单下把具有相同特征的被保人/投保人聚合起来一次性去调下游接口，结果存在各被保人/投保人的上下文里
    * 投保单级别特征：取投保单的投保单号，或者去查询投保单的状态
    * 投保单级别聚合下级批量取数特征：投保单下把具有相同特征的被保人/投保人聚合起来一次性去调下游接口，结果存在各被保人/投保人的上下文里
    * 被保人特征：单独处理一个被保人的特征，结果存在自己的上下文里
特征依赖：
    * 依赖的特征先计算
    * 无依赖的特征并行计算
    * A、B依赖C，先算C再用C的结果算A、B，C可以是特征级别里所有的级别
    * 依赖层级只能是依赖上级或者同级，应该没有向下依赖的
